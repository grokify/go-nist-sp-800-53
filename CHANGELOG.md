## [v0.11.0] - 2026-11-05

### Highlights

- Module moved to `github.com/opensecurity-dev/go-nist-sp-800-53`; update imports from `github.com/grokify/go-nist-sp-800-53`
- New `sp80053` CLI to look up controls, baselines and families, convert and check control IDs, and regenerate the docs site
- Query controls by baseline, family and implementation level (organization or system) with `Catalog.Query`

### Breaking

- Module path is now `github.com/opensecurity-dev/go-nist-sp-800-53`; versions up to v0.10.1 remain available at the old path ([`4ac27f6`](https://github.com/opensecurity-dev/nist-sp-800-53-go/commit/4ac27f6))
- Go 1.26 or later is required ([`b6bb2f1`](https://github.com/opensecurity-dev/nist-sp-800-53-go/commit/b6bb2f1))
