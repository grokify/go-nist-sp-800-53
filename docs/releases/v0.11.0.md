# Release Notes - v0.11.0

**Release date:** 2026-11-05

## Overview

This release moves the module to the OpenSecurity Institute organization at
`github.com/opensecurity-dev/go-nist-sp-800-53`, adds the `sp80053` command-line tool, and adds a query API for
selecting controls by baseline, family and implementation level.

## Highlights

- New module path: `github.com/opensecurity-dev/go-nist-sp-800-53`
- New `sp80053` CLI for looking up controls, converting and checking control IDs, and regenerating the docs site
- `Catalog.Query` selects controls by baseline, family and implementation level (organization or system)

## Breaking Changes

### Module path

The module moved from `github.com/grokify/go-nist-sp-800-53` to `github.com/opensecurity-dev/go-nist-sp-800-53`.
Versions up to v0.10.1 stay available at the old path; new versions are published only at the new one.

```bash
go get github.com/opensecurity-dev/go-nist-sp-800-53@v0.11.0
```

Update imports:

```go
// Before
import "github.com/grokify/go-nist-sp-800-53/rev5"

// After
import "github.com/opensecurity-dev/go-nist-sp-800-53/rev5"
```

Then replace `github.com/grokify/go-nist-sp-800-53` with `github.com/opensecurity-dev/go-nist-sp-800-53` across your
code and run `go mod tidy`:

```bash
grep -rl 'github.com/grokify/go-nist-sp-800-53' --include='*.go' . |
  xargs sed -i.bak 's|github.com/grokify/go-nist-sp-800-53|github.com/opensecurity-dev/go-nist-sp-800-53|g'
go mod tidy
```

### Go version

Go 1.26 or later is required.

## Added

### `sp80053` CLI

```bash
go install github.com/opensecurity-dev/go-nist-sp-800-53/cmd/sp80053@v0.11.0
```

| Command | Purpose |
|---------|---------|
| `sp80053 baselines` | Controls in each baseline, and how many each adds over the one below |
| `sp80053 families` | Families with control counts per baseline |
| `sp80053 control show <id>` | Baselines, implementation level, statement and guidance for one control |
| `sp80053 controls list` | Controls filtered by `--baseline`, `--family`, `--level` and `--include-withdrawn` |
| `sp80053 ids convert` | Convert IDs between `nist`, `nist-sort`, `oscal` and `oscal-sort` forms |
| `sp80053 ids check` | Check IDs name catalog controls; exits non-zero on invalid, unknown or withdrawn IDs |
| `sp80053 site generate` | Regenerate the control reference pages and `mkdocs.yml` |

Listing commands take `--format text|json|csv`, and the `ids` commands read from stdin when no IDs are given:

```bash
sp80053 controls list --baseline moderate --level system --format csv
sp80053 control show 'AC-2(1)'
sp80053 ids check AC-2 AU-99
```

### Query API

- `Catalog.Query(Query)` returns `ControlInfo` summaries (ID, OSCAL ID, family, title, baselines, implementation
  levels, withdrawn status), filtered by baseline, family and implementation level
- `Catalog.ControlInfo(id)` adds the rendered statement and guidance for one control
- `Catalog.CheckIDs(ids)` reports each ID as `ok`, `withdrawn`, `unknown` or `invalid`
- `Catalog.FamilyInfos()` counts each family's controls per baseline
- `Control.Statement()` renders the statement as a labelled outline (`a.`, `1.`) with parameters filled in;
  `Control.Guidance()` returns the supplemental guidance

### Implementation levels

NIST marks each control as implemented at the organization level, the system level, or both. New helpers read it:

- `Control.ImplementationLevels`, `HasImplementationLevelOrganization`, `HasImplementationLevelSystem`
- `ControlSet.FilterImplementationLevel` and `NewControlSet`
- `Controls.IDsImplementationLevelOrganization` and `Controls.IDsImplementationLevelSystem`

### Other additions

- `ControlIDs.TierIDs` and `ControlIDs.HighUpliftIDs`
- `Controls.IDs`, `ControlSet.IDsSet`, `NewIDSet`, `IDSet.FilterBaseControls`, `IDSet.IDs` and `ID.IDBase`
- Control ID lists on the generated family pages

## Changed

- The MkDocs source moved from `docsrc/` to `docs/`. The built HTML is no longer committed; CI builds the site with
  `mkdocs build --strict` and publishes it to GitHub Pages at
  [opensecurity-dev.github.io/go-nist-sp-800-53](https://opensecurity-dev.github.io/go-nist-sp-800-53)

## Known Issues

- Statements of IA-13(3), SC-42(2) and SI-10(1) reference a parameter the catalog does not define;
