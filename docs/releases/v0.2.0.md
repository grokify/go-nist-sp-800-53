# Release Notes - v0.2.0

**Release date:** 2025-05-25

## Overview

This release adds the `Control` type, single-control lookup, and resolved catalogs for each baseline.

## Added

- `Control` type and `Control.Status`
- `Catalog.Control` to retrieve one control
- `Tiers` and `ControlIDs.Tier`
- Resolved baseline catalogs for each profile

## Changed

- Remove the redundant `Rev5` prefix from type names (breaking)

## Installation

```bash
go get github.com/grokify/go-nist-sp-800-53@v0.2.0
```
