# Release Notes - v0.10.0

**Release date:** 2025-05-31

## Overview

This release renders control statements with their parameters filled in, and adds lookups by any control ID form.

## Highlights

- Controls render their statements with parameters filled in

## Added

- `Control.ControlID`, `Control.Description` and `Control.ParameterSet`
- `Parameter` and `ParameterSet` types
- `rev5tmpl.Render` for OSCAL parameter templates
- `Catalog.ControlByIDStringAny` and `Catalog.ControlByOSCALID`

## Changed

- `SiteWriter.WriteMarkdownPages` renamed from `WriteMarkdownPagesTiers` (breaking)
- `Parts.ExtractProseLines` renamed from `ExtractProse` (breaking)

## Dependencies

- Remove unneeded dependencies

## Installation

```bash
go get github.com/grokify/go-nist-sp-800-53@v0.10.0
```
