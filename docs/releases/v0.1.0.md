# Release Notes - v0.1.0

**Release date:** 2025-05-24

## Overview

Initial release: Go access to the NIST SP 800-53 Rev. 5 OSCAL catalog and baseline profiles published by NIST.

## Added

- Embedded NIST SP 800-53 Rev. 5 OSCAL catalog and baseline profiles
- `Profile` type and `ControlIDs`
- `Catalog.EnhancementIDs` and `Catalog.MustEnhancementIDs`

## Installation

```bash
go get github.com/grokify/go-nist-sp-800-53@v0.1.0
```
