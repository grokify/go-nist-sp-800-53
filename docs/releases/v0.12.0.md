# Release Notes - v0.12.0

**Release date:** 2026-11-05

## Overview

This release renames the module to `github.com/opensecurity-dev/nist-sp-800-53-go`, matching the `<standard>-go`
naming of the organization's other Go libraries. There are no API changes.

## Breaking Changes

### Module path

The module moved from `github.com/opensecurity-dev/go-nist-sp-800-53` to
`github.com/opensecurity-dev/nist-sp-800-53-go`. v0.11.0 stays available at the previous path, and versions up to
v0.10.1 at `github.com/grokify/go-nist-sp-800-53`; new versions are published only at the new path.

```bash
go get github.com/opensecurity-dev/nist-sp-800-53-go@v0.12.0
go install github.com/opensecurity-dev/nist-sp-800-53-go/cmd/sp80053@v0.12.0
```

Replace either earlier path across your code and run `go mod tidy`:

```bash
grep -rlE 'github.com/(grokify|opensecurity-dev)/go-nist-sp-800-53' --include='*.go' . |
  xargs sed -i.bak -E 's#github.com/(grokify|opensecurity-dev)/go-nist-sp-800-53#github.com/opensecurity-dev/nist-sp-800-53-go#g'
go mod tidy
```
