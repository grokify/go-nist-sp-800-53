# Release Notes - v0.6.0

**Release date:** 2025-05-26

## Overview

This release adds control ID parsing and formatting across NIST and OSCAL forms, ID sets, and per-family summaries.

## Added

- `ParseID`, `IDs`, `ParseIDs` and `IDSet`
- `ID.FormatType`, `IDs.FormatIDType`, `IDs.FilterByTier` and `ControlIDs.TierMap`
- `Family`, `FamilySet` helpers and `ControlSet.FamilySet`
- `ControlProfileStatus` and `ControlIDs.ControlProfileStatus`
